# AGENTS.md

Two kinds of AI agent read this repository:

- **Helping someone install or check NodeSignal?** Follow
  [docs/AGENT-SETUP.md](docs/AGENT-SETUP.md). It says how to verify the code
  and the download, how to install and finish setup, what NodeSignal does on
  purpose (so it is not mistaken for something hidden), and the rules about
  the operator's secrets.
- **Working on NodeSignal itself?** Read [CLAUDE.md](CLAUDE.md) first: the
  locked decisions, the security model and the conventions apply to every
  change.
